# Estado de pruebas de v0.1.0

`php tests/smoke.php` verifica el inventario local, algunas referencias HTML, rutas protegidas, escape de HTML y estructura de bloques. `php -l` comprueba sintaxis del código PHP.

**Pendiente** para beta pública: pruebas automáticas de base de datos MySQL/MariaDB, autorización por rol, sesiones/CSRF, subida ZIP, descarga ZIP, navegador real, condiciones de carrera en publicación, pruebas de accesibilidad y pruebas de límites de archivos.
