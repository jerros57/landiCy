# Política de licencia y cooperación comunitaria

- **Código de LandiCy:** GNU AGPLv3 o, a elección del receptor, cualquier versión posterior publicada por la FSF (`AGPL-3.0-or-later`). Texto completo en `LICENSE` / `COPYING`.
- **Salida generada:** permiso adicional en `LICENSE-OUTPUT-EXCEPTION.md` para los fragmentos originales de LandiCy incluidos en webs exportadas. El usuario conserva sus derechos sobre su contenido propio.
- **Obligación concreta:** si alguien opera una versión **modificada** de LandiCy para usuarios remotos, debe ofrecer a esos usuarios el Código Fuente Correspondiente de su versión, de conformidad con la sección 13 de AGPLv3. Quien redistribuya software sujeto a AGPL también debe cumplir las obligaciones aplicables.
- **No se puede imponer:** no existe obligación de desarrollar funciones nuevas, mantener el programa ni enviar un pull request al repositorio oficial. La licencia tampoco confiere el derecho de exigir un contrato de trabajo o contribución gratuita.
- **Código de terceros:** debe usarse únicamente con permisos/licencias compatibles. Las plantillas aportadas por colaboradores necesitan permiso adicional específico si se pretende que la salida sea libre de licencias de plantillas.
- **Avisos:** conservar la autoría verdadera de cada archivo, el texto de licencia y las notas de modificación. Al desplegar versiones modificadas accesibles por red, ofrecer una ruta clara y efectiva para obtener la fuente correspondiente. Se recomienda enlazar un repositorio público que contenga la versión realmente desplegada.
- **Historial:** v0.1.0 fue entregada bajo MIT. Quien obtuvo legalmente esa copia conserva los derechos concedidos entonces; el cambio de licencia no revoca permisos previos. Verificar la titularidad y acuerdos de futuros colaboradores antes de cambiar licencias.

Referencia oficial: https://www.gnu.org/licenses/agpl-3.0.en.html

Nota: información general, no asesoría jurídica para una jurisdicción concreta.
