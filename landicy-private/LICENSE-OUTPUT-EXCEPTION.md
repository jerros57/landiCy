# Permiso adicional para sitios exportados por LandiCy

**Permiso adicional bajo la sección 7 de GNU AGPLv3.** Los titulares de derechos
sobre los componentes originales de LandiCy utilizados para generar plantillas
HTML, CSS y JavaScript conceden permiso adicional para utilizar, modificar y
distribuir sitios web generados mediante LandiCy, incluidos los fragmentos de
plantilla originales incorporados al sitio exportado, bajo las condiciones que
el autor de ese sitio elija. El sitio exportado **no adquiere automáticamente**
la licencia AGPL solamente por incluir esos fragmentos originales.

Este permiso **no** autoriza distribuir una copia o modificación del propio
programa LandiCy, su editor, panel administrativo, generador o motor de
reconocimiento al margen de GNU AGPLv3. Las modificaciones al programa LandiCy
siguen sometidas a esa licencia, incluida su sección 13 cuando corresponda.

El permiso se aplica exclusivamente a los fragmentos y plantillas originales
sobre los que quienes conceden esta excepción tienen derechos. No cubre código,
fuentes, imágenes, contenido ni plantillas añadidas por terceros: se debe
respetar la licencia de cada elemento externo.

Consulta [LICENSE](LICENSE) para el texto íntegro de GNU AGPLv3. Si otros
autores contribuyen plantillas al proyecto, deben declarar explícitamente si
conceden este mismo permiso para sus aportaciones.
